## Phát hiện và quyết định

- README frontend mô tả khung mặc định, không phản ánh tích hợp hiện tại: viết lại và mô tả dữ liệu/quyền riêng tư.
- Test backend dùng `/plants` đã không còn là route vườn: đổi sang `/garden`; kiểm tra giới hạn phân trang ở endpoint notifications hiện hỗ trợ phân trang. Giữ assertion quyền sở hữu lấy từ token.
- Theme chỉ có lightTheme, controller tối không được nối: bỏ công tắc không hoạt động, không tự xây thêm dark mode.
- Release trước đó dùng debug signing: cấu hình khóa release riêng và hướng dẫn đăng ký dấu vân tay chứng chỉ.
- Bổ sung test validation, token logout/refresh, chống bấm lặp khi loading, trợ năng nút chính.

## Đính chính sau kiểm tra luồng Auth

Nhận định ban đầu rằng Google login bắt buộc fingerprint release không áp dụng cho app hiện tại. Code dùng launchUrl và Supabase OAuth/PKCE qua trình duyệt, không dùng Google Sign-In native. README frontend và RELEASE.md đã được sửa; cần kiểm thử callback/deep link trên APK release, không cần thêm SHA chỉ vì đổi khóa ký.
