# Đóng góp

Chọn issue có tiêu chí nghiệm thu, nhận task và tạo branch từ main mới nhất. Giữ PR trong phạm vi một thay đổi. Chạy `npm run lint`, `npm run typecheck`, `npm test` tại root hoặc `dart format lib test`, `flutter analyze`, `flutter test` trong apps/mobile. Khi đổi dependency hãy commit cả lockfile. Khi đổi schema hãy thêm migration và cập nhật API/DB docs.

Quy trình review, xử lý conflict và cấp quyền nằm trong [TEAM_WORKFLOW](docs/TEAM_WORKFLOW.md).
